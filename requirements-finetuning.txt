# requirements-finetuning.txt
# ----------------------------------------------------------------------------
# Dependências ADICIONAIS para o pipeline de fine-tuning LoRA/PEFT (Fase 3).
# Instale por cima do requirements.txt principal:
#
#   pip install -r requirements.txt
#   pip install -r requirements-finetuning.txt
#
# O treino roda em três cenários:
#   - GPU NVIDIA  : quantização 4-bit (QLoRA) via bitsandbytes;
#   - Apple Silicon (MPS) : sem quantização, modelo em float16;
#   - CPU         : sem quantização, modelo em float32 (lento).
#
# O `train_lora.py` detecta o device e desliga a quantização sozinho quando não
# há CUDA, porque bitsandbytes só tem kernels para GPU NVIDIA.
#
# Mantido separado do requirements.txt porque torch/bitsandbytes têm builds
# específicos por SO/CUDA e não são necessários para rodar o restante do
# projeto (pipeline tabular, imagem, AG, app Streamlit) em CPU.
# ----------------------------------------------------------------------------

# Versões testadas nesta entrega (fine-tuning executado em Apple M4 / MPS).
